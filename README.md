# Sri Padmavathi Construction — GitHub Pages Website

A responsive, professional construction company website for Sri Padmavathi Construction, Chennai.

## Included
- Construction-themed 3D/parallax hero section
- Home, About, Services, Projects, Packages, FAQ, Booking and Contact sections
- Project filtering and click-to-enlarge project gallery
- Mobile navigation
- Scroll progress indicator, reveal animations and back-to-top button
- WhatsApp, phone, email and Google Maps quick actions
- Google Form booking button connected to the supplied form
- Running quality/value strip
- GitHub Pages-friendly relative image paths

## Google Form
Create the booking form using `asrlotus@gmail.com`, then the booking button is connected to `https://forms.gle/EDruMxXNg35GrA1A7`.

Recommended fields:
1. Name
2. Phone / WhatsApp
3. Project type
4. Site location
5. Approximate built-up area
6. Preferred date
7. Preferred time slot
8. Project requirements

Configure Google Forms response notifications for `asrlotus@gmail.com`.
